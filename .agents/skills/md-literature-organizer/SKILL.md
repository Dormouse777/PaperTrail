# 整理导出文献

只操作用户给出的明确根目录与分类规则，先列出计划。此公开候选不附带作者私人分类表或重命名脚本；可用当前文件工具完成核查，不能假设存在未交付的helper。

- 管理/索引中的材料先查bundle和映射引用；普通获取保留原下载器文件名，不能顺手改名破坏追溯。
- 对比PDF元数据/首页实际题名和Markdown主标题；期刊名、Open Access、作者年份、节标题及截断题名不是论文题名。多个名字一致也不证明正确。
- 只在题名核实后规范Windows非法字符，保留有意义的Unicode。文件夹、主PDF和Markdown一致变更，所有嵌套JSON、图片、layout等资源原样保留。
- 逐项核碰撞和最终绝对路径，不跨出批准的源/目标目录，不跟随链接/重解析点批量移动。对已索引材料先核如何同步来源引用，不能仅改目录。
- 用SHA报告精确重复组，不自动删除或覆盖。分类只用本次提供/批准的目录和规则；不把某个研究者的主题表作为通用规则。
- 交付逐项旧/新路径、核验依据、碰撞和未完成项；更名/分类不自动触发入库、重Embedding或新的下载。
